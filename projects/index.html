Reservoir Assessment Tool (RAT) Python package · ratdocs.io

A conda-installable Python framework for globally monitoring reservoir operations – inflow, storage change, evaporation, surface area, and outflow – using satellite remote sensing and hydrological modelling. Adopted by the Mekong River Commission as an operational decision-support tool.

software reservoirs remote-sensing
ResORR Reservoir Operations driven River Regulation

A globally scalable satellite-data-driven algorithm that predicts regulated river flow by coupling satellite-estimated reservoir state with a mass-balance model. Validated on the Cumberland River Basin; improves regulated flow simulation by >50% over unregulated models.

RAT-Mekong Decision Support System Operational monitoring for the Mekong Basin

An operational dashboard for near-real-time monitoring of reservoir dynamics across the Mekong River Basin, co-developed with the Mekong River Commission (MRC) and adopted as an official decision-support tool.
