The Reservoir Assessment Tool (RAT) is now available as a conda-installable Python package with a command-line interface, CI/CD pipeline, and full documentation at [ratdocs.io](https://ratdocs.io). The paper describing the package is published in *Digital Water*.

[Read the paper](https://doi.org/10.1080/28375807.2025.2487762)
